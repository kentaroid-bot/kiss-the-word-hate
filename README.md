# 憎むにキスを

作品提供：ケンタロウ。登録管理：つづきの森管理チーム。

[本文を読む](manuscript/01.md) / [世界と森での位置](world.md)

つづきの森の最奥に置く、一話で完結する木です。この木に次話は追加しません。別の「小石の木」で、この話から『反芻の庭と、靴底の小石』へ進みます。森内でこの話に直接接続する作品は小石だけとし、小石以降は通常ルールで分岐できます。
